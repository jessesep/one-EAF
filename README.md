# ONE Ethical AI Foundation

An open source initiative implementing [OECD AI Principles](https://oecd.ai/en/ai-principles) for everyone.

---

## Mission

We translate globally-adopted AI ethics standards into practical, auditable tools. The OECD AI Principles, endorsed by 46 countries including all G20 nations, should not remain abstract policy. They should be actionable.

> We don't create new principles. We implement the ones the world already agreed on.

---

## OECD AI Principles

Everything we build serves these five principles:

1. **Inclusive Growth, Sustainable Development and Well-being** - AI should benefit people and the planet
2. **Human Rights and Democratic Values** - AI must respect privacy, fairness, and human dignity
3. **Transparency and Explainability** - People should understand how AI affects them
4. **Robustness, Security and Safety** - AI systems must be secure and resilient
5. **Accountability** - Developers and deployers must be accountable for outcomes

---

## The Eight Golden Rules

| Rule | Principle | Description |
|------|-----------|-------------|
| 1. Your Data, Your Device | Privacy | AI processes data locally by default |
| 2. No Training Without Consent | Privacy | Your work is never used without permission |
| 3. Transparent Data Flow | Transparency | Know where your data goes |
| 4. Freedom From Lock-In | Inclusive | Export, switch, self-host freely |
| 5. Explicable Decisions | Explainability | Understand why AI decides |
| 6. Security By Default | Safety | Strong encryption, minimal attack surface |
| 7. Honest About Limitations | Accountability | Clear disclosure of capabilities |
| 8. Compute For Good | Well-being | Idle compute should help humanity |

## Compute For Good

If you have compute, you have an ethical obligation to use it for good.

Join humanitarian computing projects:
- [Folding@home](https://foldingathome.org) - Protein folding for disease research
- [BOINC](https://boinc.berkeley.edu) - Open infrastructure for network computing
- [World Community Grid](https://www.worldcommunitygrid.org) - Health and sustainability research

## Certification Tiers

**Tier 1: EAF Compliant** - Meets minimum requirements for rules 1-7

**Tier 2: EAF Certified** - Independent audit verification, meets rule 8

**Tier 3: EAF Gold** - Exceeds requirements, active compute donation
