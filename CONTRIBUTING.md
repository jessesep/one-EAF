# Contributing to ONE Ethical AI Foundation

Thank you for your interest in contributing.

## How to Contribute

### Discussions
- Open an issue to discuss ideas before submitting PRs
- Be respectful and constructive

### Pull Requests
1. Fork the repository
2. Create a branch for your changes
3. Submit a PR with a clear description

### What We Need
- **Documentation improvements** - Clarity, translations
- **Certification criteria** - Review and refinement
- **Tools** - Self-assessment, data flow visualization
- **Auditors** - Community verification process

## Code of Conduct

Be respectful. Be constructive. Be helpful.

We do not tolerate harassment, discrimination, or bad faith engagement.

## Questions

Open an issue or start a discussion.
